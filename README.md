## AgentCore deployment notes - AgentCore deployment is configured for Python 3.12. - AWS resources are deployed using the `Strands-Hackathon` IAM user/profile rather than the root/default account for normal project work. - CDK bootstrap must be completed for the target AWS account and region before CDK-backed AgentCore resources can deploy. - IAM permissions required some adjustment during setup; permission errors should be checked against the AgentCore/CDK resources being created rather than solved by repeatedly adding broad permissions. - Verify the AWS profile and region before deploying: `aws sts get-caller-identity --profile strands-hackathon`
